Como instalar

  1. Gmail (web): Configurações → Ver todas as configurações → Geral → Assinatura → Criar nova → cole (Ctrl/Cmd+V) → Salvar alterações. Marque como padrão para novos e-mails e respostas.
  2. Apple Mail (Mac): Mail → Ajustes → Assinaturas → "+" → cole. Desmarque "Sempre usar minha fonte de mensagem padrão".
  3. Outlook (novo/web): Configurações → Contas → Assinaturas → cole → Salvar.
  4. Celular (Gmail app): não aceita HTML. Deixe só texto: Nome · Cargo · Tela Vertical · (43) 99696-0078 · uma empresa do Grupo Predial.

Regras

  1. Não mude cores, fonte ou ordem. A assinatura "uma empresa do Grupo Predial" é obrigatória.
  2. Não adicione frases motivacionais, imagens extras ou banners de campanha sem aprovação.
  3. Na resposta de e-mails longos, o Gmail já reduz a assinatura; não precisa apagar.
  4. Se o botão de copiar não funcionar (Safari antigo), use "Copiar código HTML" e cole no editor de assinatura em modo HTML.
